# Industry Expectations for Fresher Candidates

## What Employers Look For in Freshers

### Technical Skills
- **Core fundamentals over frameworks**: Employers expect strong CS fundamentals (data structures, algorithms, OOP, databases, networking) more than knowledge of any specific framework.
- **One language proficiency**: Deep proficiency in one language (Python, Java, C++, JavaScript) is preferred over surface-level knowledge of many.
- **Problem-solving mindset**: Ability to break down an unfamiliar problem, not just recall solutions.
- **Version control**: Git basics are mandatory — commit history, branching, pull requests.

### Projects and Portfolio
- At least 1–2 end-to-end projects (not just tutorials) that solve a real problem.
- Projects should be on GitHub with a clear README explaining the problem, approach, and how to run it.
- Deployed or demo-able projects are a strong differentiator.
- Open-source contributions (even small ones) demonstrate initiative.

### Soft Skills
- Clear verbal and written communication — ability to explain your thinking.
- Learning agility — demonstrating you can pick up new technologies quickly.
- Team collaboration — most hiring managers ask about group project experiences.
- Ownership mentality — showing you take responsibility for outcomes, not just assigned tasks.

## What Freshers Should NOT Worry About

- Years of experience with a specific tool — this is expected to be zero.
- Not knowing every library or framework — willingness to learn matters more.
- Having worked at a famous company — strong academics + projects compensate.

## Interview Process (Typical for Tech Companies)

1. **Online Assessment (OA)** — Competitive programming / aptitude (LeetCode Easy–Medium level)
2. **Technical Round 1** — Data structures, algorithms, coding problems
3. **Technical Round 2** — System design basics (for SDE roles), project deep-dive
4. **HR Round** — Background, motivation, culture fit, offer discussion

## Preparation Timeline for Freshers

| Focus Area | What to Prepare |
|---|---|
| DSA | Arrays, Strings, Linked Lists, Trees, Graphs, DP (50–100 problems) |
| CS Fundamentals | OS, DBMS, CN, OOP — standard interview theory questions |
| Projects | 2 projects ready to deep-dive into; know every line of your code |
| Behavioral | 5–6 STAR stories from academic/project experience |
| Company Research | Product, recent news, tech stack, culture, values |

## Common Mistakes Freshers Make

- Memorizing solutions without understanding them — interviewers probe the "why"
- Only preparing DSA and ignoring CS fundamentals
- Saying "we did X" without clarifying their individual contribution
- Not asking clarifying questions before solving a problem in coding interviews
- Being unable to admit "I don't know" — it's better than guessing wrong
